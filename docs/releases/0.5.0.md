**Early preview, unsigned.** 0.5.0 adds the ADR 0001 block taxonomy, tautomer enumeration, the
optional ML scorer role, DLPNO-CCSD(T), ORCA couplings, Gaussian solvation and a measured-uncertainty
report. Read *Upgrade* first: **the project schema is now version 3, and 0.4.0 projects are refused,
not migrated.**

## Upgrade

- **`schemaVersion: 3` is a breaking vocabulary change.** A 0.4.0 (version 2) project opens in 0.4.0,
  not here. Finish or export it before upgrading; this release does not silently reshape it.
- The new blocks are `input`, `prepare`, `generate`, `calculate`, `analyse` and `output`, with
  `generate` owning `produces: "conformers" | "tautomers"`.
- Run-record documents keep their own version; `--schema-version 1` still emits the v1 body.

## New in 0.5.0

- **Tautomer and protomer sets.** An RDKit sidecar enumerates candidates labelled `t1`, `t2`, … with
  canonical SMILES, formula and `origin` provenance. Each candidate fans out into its own
  calculation, and the report prints the spread across the set — never a Boltzmann average across
  distinct molecules.
- **`prepare` blocks.** In-app UFF relaxation, Open Babel `--gen3d`, or a scorer-driven relaxation,
  each recorded as one prepared structure.
- **Optional ML scorer role.** Re-rank a Generate ensemble, run a Calculate single point, or relax a
  Prepare block. The scorer is guarded by element/charge/spin, units are converted explicitly, and a
  result without provenance is refused.
- **ORCA DLPNO-CCSD(T) single points.** `NormalPNO`/`TightPNO`, explicit `RIJCOSX` and auxiliary
  bases, and parser provenance for `TCutPNO`, correlation energy and the triples correction.
- **ORCA hyperfine and spin-spin couplings** populate the EPR and NMR cards, with 0-based indexing
  stated in the record.
- **Gaussian SCRF solvation** records model, solvent, cavity, radii and the SCF energy in solution;
  the SMD non-electrostatic term is kept separate and marked as already in the total.
- **Measured uncertainty** in the report: method spread from rungs that ran, conformer spread beside
  the Boltzmann-weighted value, and barrier-to-rate propagation. No literature averages.
- **Conformer choices:** in-app UFF, Open Babel MMFF94/MMFF94s/UFF, and generator-scoped `method`.
- **Analysis:** EPR, DP4/DP4+, QTAIM/NCI, ESP-coloured surfaces, spin-state sweeps, derivative
  structures, series expansion, a pre-run cost estimate and a per-task wall-clock limit.

## Fixed

- Open Babel 3.2.x `--conformer` is refused before spawning; a signalled child is never a completed
  run (#239).
- Conformer `method` now follows the generator, and legacy `gfn2` placeholders migrate (#240).
- `formchk -3` is taught everywhere; the fchk reader accepts 2000+ basis functions with `NBasis`
  shape checks (#242, #243).
- Gaussian solvation is recorded instead of dropped (#223).
- Restart artifacts are validated per engine, and the run console seeds a detected executable
  (#231, #233).

## What this release does not claim

- **No app-driven run against a licensed Gaussian, xTB, ORCA or CREST binary.** Parsers are pinned by
  real logs and a 25-case G16 Rev A.03 peer sweep; the app's own run console driving a licensed job
  remains unverified.
- **The Python sidecars are not embedded in the installer.** Tautomer enumeration and the AIMNet2
  scorer require your own Python environment and the script from this repository at the release tag
  (`scripts/tautomer-enumerator.py`, `scripts/aimnet2-scorer.py`). RDKit, torch and the weights are
  yours to install.
- **Windows sidecar runtime tests are skipped.** The Windows installer is built and the Linux sidecar
  tests run in CI; the Windows package workflow runs the remaining suite.
- **Installers are unsigned**, have not been installed on a clean machine, and there is no macOS
  build.
- ROA needs a Gaussian 16 B.01+ log the repository does not have. A binary ChemDraw `.cdx` is still
  refused by name; only CDXML is read.
